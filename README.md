# Домашні завдання — міні-сайт

Статичний сайт для GitHub Pages: `index.html` — календар, `dz/<дата>.html` — сторінки із завданнями,
`dz/index.js` і `dz/index.json` — список сторінок. Збирається скриптом `site_publish.py`
з проєкту telegram-homework; руками тут нічого правити не треба.

`dz/holidays.js` і `dz/holidays.json` — канікули (`site_publish.py holiday add <від> <до> --title …`):
календар зафарбовує ці дні окремим кольором і показує рядок «Канікули: …».
